# Política de dados

## Inventário de acesso restrito

O inventário de deslizamentos utilizado no projeto não será publicado
neste repositório nem disponibilizado pelo WebGIS. (REVISAR)

## Conteúdo que não deve ser publicado

- Pontos e polígonos das ocorrências.
- Coordenadas, endereços e identificadores dos registros.

## Produtos públicos

Os mapas de suscetibilidade serão publicados após revisão.

## Revisão antes da publicação

Antes de cada commit, verificar os arquivos e as saídas incluídas.
A mesma revisão se aplica a anexos de issues, pull requests e releases.

O .gitignore é uma proteção complementar e não impede a publicação
de arquivos já rastreados pelo Git.
